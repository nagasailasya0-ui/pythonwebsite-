    Python Syntax Cheat Sheet

    Concept Syntax Pattern Description
    Print & F-Strings print(f"Hi, {name}!") Outputs formatted string with interpolated variables
    String Slicing seq[start:stop:step] Extracts sub-sequence (stop index is excluded)
    List Comprehension [x*2 for x in nums if x>0] Concise, readable syntax for generating new lists
    Dictionary Safe Lookup dict.get(key, default) Returns fallback instead of throwing KeyError
    Try / Except try: ... except Err: ... Catches runtime exceptions gracefully
    Context Manager with open("file.txt") as f: Guarantees resources and file streams are closed properly
    Class Definition class Hero(Parent): Defines class with inheritance and methods
